## 自动化流程

OpenClaw 支持完整的开发自动化：

1. **代码生成** → 使用 OpenCode CLI + GPT5.2
2. **自动测试** → Vitest / pytest
3. **提交代码** → Git 自动提交
4. **推送代码** → GitHub 自动推送
5. **自动发版** → GitHub Release
